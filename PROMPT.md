# Промт для ИИ — GRABIT

Собери продукт **GRABIT** по этому описанию. Домен: **grabitmap.com**.  
Пиши код и тексты интерфейса сразу под это имя и этот домен.  
Стек: **Rust**, сайт **axum + SQLite**, один бинарник. Секреты только из переменных окружения.

Не добавляй историю проекта и сравнения. Реализуй систему как она должна работать.

---

## Продукт

**GRABIT** — глобальная карта людей, возможностей и живого движения.

Площадки:

- сайт https://grabitmap.com  
- мобильное приложение с тем же аккаунтом  

Главные сущности:

- пользователь приложения  
- город  
- объявление  
- шаг / активность  

Название в интерфейсе: **GRABIT**.  
Короткий слоган: карта людей и возможностей.

---

## Карта

Сразу полный справочник:

- все континенты  
- все страны  
- все нормальные города  

Навигация: мир → континент → страна → город.  
На экране не вываливать весь справочник. Показ через поиск с подсказками и через цепочку континент → страна → город.

Поиск работает по всему миру без выбранного города.  
Континент, страна, город — необязательные фильтры.

Города нет в справочнике — только заявка администратору. Свободный ввод нового города запрещён.

## Профиль

У аккаунта:

- устойчивый публичный id  
- отображаемое имя  
- город  
- отметки возможностей  
- объявления  
- рейтинг  
- статистика шагов  

Отметки ставятся и снимаются в общих списках.  
В «Мой город» — сводка. Снятая отметка остаётся пустым пунктом, пока пользователь не очистит пустые отдельно.

## Категории

Полный набор сразу, только приличные пункты:

- профессии — все нормальные рабочие специальности  
- работа: предлагаю / ищу / подработка  
- бизнес: есть дело / ищу партнёра / есть точка / ищу точку  
- жильё: сдам / сниму / помещение  
- транспорт: есть транспорт / готов возить / ищу перевозку  
- капитал: готовность участвовать, только диапазоны  
- команда: соберу / ищу людей / готов присоединиться  
- знания: могу научить / ищу наставника

## Объявление

Поля: автор, город, категория, заголовок, текст, статус.

Статусы: черновик, на проверке, опубликовано, отклонено, скрыто.

Публичный поиск — только опубликованные активные.

Карточка: заголовок, место, категория, краткий текст, рейтинг автора.  
«Написать» — только для своего, открывает внутренний чат с автором.

Ссылка на карточку: `https://grabitmap.com/a/{id}`

---

## Витрина города

У города есть страница в GRABIT и список внешних витрин.

Внешняя витрина — канал доставки короткой карточки: текст + ссылка на `grabitmap.com`.

К городу можно привязать несколько витрин разных типов и несколько одного типа.

Публикация:

1. объявление сохраняется в GRABIT  
2. статус «опубликовано»  
3. короткая карточка уходит во все включённые витрины города  
4. переписка, рейтинг, шаги и профиль остаются в GRABIT  

Код объявлений работает со списком витрин, не с конкретной сетью.

## Внутренний чат

Только зарегистрированные.

Диалог двух аккаунтов GRABIT.  
Сообщения в одной таблице. После обновления страницы история на месте.  
Нельзя писать себе. Есть блок.

---

## Шагомер

Встроенная активность тела.

Зарегистрированный включает шагомер в приложении.  
Шаги считаются на устройстве и синхронизируются в профиль GRABIT.

Хранить всю историю:

- шаги по минутам/часам (сырой поток можно сжимать)  
- итог за день  
- итог за неделю / месяц / год  
- итог за всё время  
- город, в котором день зафиксирован, если геолокация разрешена  

Экраны:

- сегодня  
- календарь дней  
- график  
- рейтинг города  
- рейтинг страны  
- личный рекорд  

Правила:

- гость локально может видеть счётчик на телефоне, в облако и в рейтинги не попадает  
- один аккаунт — одна облачная история  
- нельзя вручную дописать себе шаги  
- подозрительные скачки помечаются на модерацию  
- история не удаляется при обновлении приложения  
- пользователь может скрыть шаги из публичного рейтинга, личная история остаётся  

Шаги не заменяют объявления. Это отдельный слой доверия и живого присутствия в городе.

## Архитектура

Один бинарник Rust. Одна SQLite. Один тип пользователя.

Модули отдельными папками:

- `core` — пользователи, карта, объявления, поиск  
- `windows` — витрины города  
- `chat` — личка  
- `rating` — отзывы  
- `steps` — шагомер и история  
- `admin` — админка  

Модуль отключается флагом и удалением папки. Ядро не зависит от витрин, чата и шагов.

Запуск на домене **grabitmap.com**.  
В письмах, ссылках, манифесте приложения и Open Graph — только GRABIT и grabitmap.com.

## Что должно получиться

Человек заходит на **grabitmap.com**, видит GRABIT и полную карту мира, ищет без обязательного города, открывает объявление.  
Гость смотрит.  
Свой публикует, пишет в чат, копит историю шагов, попадает в рейтинг города.  
Опубликованное объявление живёт в GRABIT и уходит короткой карточкой на витрины этого города.
