## 2. Карта

Сразу полный справочник:

- все континенты  
- все страны  
- все нормальные города  

Навигация: мир → континент → страна → город.

На экране не показывать весь справочник простынёй. Только:

- поиск по названию с подсказками  
- цепочка континент → страна → город  

Поиск объявлений и людей работает по всему миру **без выбранного города**.  
Континент, страна, город — необязательные фильтры.

Города нет в справочнике — пользователь подаёт заявку на **grabitmap@gmail.com** и через форму в приложении. Администратор принимает или отклоняет. Свободный ввод города запрещён.

Публичные адреса:

- главная: https://grabitmap.com  
- поиск: https://grabitmap.com/search  
- город: https://grabitmap.com/city/{slug}  
- объявление: https://grabitmap.com/a/{id}  
- профиль: https://grabitmap.com/u/{public_id}  
- админка: https://grabitmap.com/admin

## 4. Аккаунт

Регистрация только в GRABIT (сайт или приложение).

Поля: почта, пароль / код, отображаемое имя, город, публичный id.

Почта проекта для писем системы: **grabitmap@gmail.com**.

У аккаунта:

- устойчивый public_id  
- имя  
- город  
- отметки возможностей  
- объявления  
- рейтинг  
- история шагов  
- настройки приватности  

Отметки ставятся и снимаются в общих списках.  
«Мой город» — сводка. Снятая отметка остаётся пустым пунктом, пока пользователь отдельно не очистит пустые.

Нельзя писать себе в чат.  
Нельзя иметь два облачных шагомера на один аккаунт.

## 5. Категории

Полный набор сразу. Только приличные пункты.

- профессии — все нормальные рабочие специальности  
- работа: предлагаю / ищу / подработка  
- бизнес: есть дело / ищу партнёра / есть точка / ищу точку  
- жильё: сдам / сниму / помещение  
- транспорт: есть транспорт / готов возить / ищу перевозку  
- капитал: готовность участвовать, только диапазоны  
- команда: соберу / ищу людей / готов присоединиться  
- знания: могу научить / ищу наставника

## 6. Объявление

Поля: автор, город, категория, заголовок, текст, статус, время.

Статусы: черновик, на проверке, опубликовано, отклонено, скрыто.

Публичный поиск показывает только опубликованные и активные.

Карточка: заголовок, место, категория, краткий текст, рейтинг автора.  
«Написать» — только свой, открывает внутренний чат с автором.

---

## 7. Витрина города

У города есть страница в GRABIT и список внешних витрин.

Внешняя витрина — канал доставки короткой карточки: текст + ссылка на https://grabitmap.com/a/{id}

К одному городу можно привязать несколько витрин разных типов и несколько одного типа.

Публикация:

1. объявление сохраняется в GRABIT  
2. получает статус «опубликовано»  
3. короткая карточка уходит во все включённые витрины этого города  
4. переписка, рейтинг, шаги и профиль остаются в GRABIT  

Код объявлений работает со списком витрин. Он не знает конкретную внешнюю сеть как основу продукта.

После обновления страницы история на месте.  
Есть доставка и прочтение.  
Есть блок пользователя.  
Список диалогов и открытый диалог читают одни данные.

---

## 9. Шагомер

Отдельный модуль активности.

Зарегистрированный включает шагомер в приложении.  
Шаги считаются на устройстве и синхронизируются в GRABIT.

Хранить всю историю:

- дневной итог  
- неделя / месяц / год  
- всё время  
- календарь дней  
- город дня, если геолокация разрешена  

Экраны: сегодня, календарь, график, рейтинг города, рейтинг страны, личный рекорд.

Правила:

- гость не попадает в облако и в рейтинги  
- один аккаунт — одна история  
- ручная накрутка запрещена  
- подозрительные скачки — на модерацию  
- история не пропадает при обновлении приложения  
- можно скрыть шаги из публичного рейтинга, личная история остаётся  

Шаги не заменяют объявления.

## 13. Архитектура

Один бинарник Rust. Одна SQLite. Один тип пользователя.

Папки:

- `core` — пользователи, карта, объявления, поиск  
- `windows` — витрины  
- `chat` — личка  
- `rating` — отзывы  
- `steps` — шагомер  
- `admin` — админка  
- `mail` — письма с grabitmap@gmail.com  

Модуль снимается флагом и удалением папки. Ядро не зависит от витрин, чата и шагов.

Во всех письмах, манифесте, Open Graph, иконках и текстах: **GRABIT**, **grabitmap.com**, **grabitmap@gmail.com**.
